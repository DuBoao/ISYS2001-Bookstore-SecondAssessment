# Team Roles & User Story Assignment
## Team Members
1. Member A: Repository Owner, Developer
2. Member B: Documentation Lead, Developer
3. Member C: Tester & Release Manager, Developer

## Individual Responsibilities
### Member A
- Create GitHub repository, configure access permission and branch protection rule for main branch.
- Develop assigned user stories.
- Review PR created by other team members.
- Help resolve Git issues.

### Member B
- Responsible for project initiation document and project planning document.
- Maintain team role document.
- Develop assigned user stories.
- Review PR created by other team members.

### Member C
- Responsible for system testing, write test document.
- Prepare design document and deployment document.
- Create GitHub release v1.0.0 after all code merged.
- Develop assigned user stories.
- Review PR created by other team members.
